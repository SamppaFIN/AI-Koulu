Visuaalisen suunnittelun tehtävä on tehdä sisällöstä luettavaa ja rakenteesta näkyvää. Tässä luvussa käsitellään kolme osa-aluetta, joihin liittyy mitattavia vaatimuksia: typografia, värit ja liike.

## 2.1 Typografia ja luettavuus

WCAG 2.2 asettaa tekstille joustavuusvaatimuksia. Sivun pitää kestää käyttäjän omat asetukset <Reference id="w3c2023" />:

| Kriteeri | Taso | Vaatimus |
|---|---|---|
| 1.4.4 Resize Text | AA | Tekstin voi suurentaa 200 %:iin ilman, että sisältöä tai toimintoja katoaa |
| 1.4.10 Reflow | AA | Sisältö toimii 320 CSS-pikselin levyisenä ilman vaakavieritystä |
| 1.4.12 Text Spacing | AA | Mitään ei katoa, kun riviväli on 1,5 × fonttikoko, kappaleväli 2 ×, kirjainväli 0,12 × ja sanaväli 0,16 × |
| 1.4.8 Visual Presentation | AAA | Muun muassa rivin pituus enintään 80 merkkiä |

Käytännössä vaatimukset toteutuvat, kun fonttikoko ja välit annetaan suhteellisina yksikköinä (`rem`, `em`), tekstisäiliöille ei anneta kiinteää korkeutta ja asettelu joustaa leveyden mukaan.

**Muuttuva fontti** (variable font) sisältää yhdessä tiedostossa kirjasintyypin monta muunnelmaa erillisten tiedostojen sijaan. Rekisteröityjä akseleita on viisi: paino (`wght`), leveys (`wdth`), kursiivi (`ital`), kallistus (`slnt`) ja optinen koko (`opsz`) <Reference id="mdn-variable-fonts" />. Yksi tiedosto voi korvata usean painon erilliset lataukset, mikä vähentää pyyntöjä (luku 5).

**Sujuva typografia** skaalaa koon ikkunan leveyden mukaan rajojen sisällä:

```css
h1 { font-size: clamp(1.75rem, 1.2rem + 2vw, 2.75rem); }
```

`clamp(min, toivottu, max)` pitää koon välillä 1,75–2,75 rem. Koska minimi ja maksimi ovat `rem`-yksikköjä, käyttäjän fonttiasetus vaikuttaa yhä kokoon.

## 2.2 Kontrastisuhde

WCAG määrittelee kahden värin kontrastisuhteen niiden suhteellisista luminansseista *L₁* (vaaleampi) ja *L₂* (tummempi) <Reference id="wcag-contrast" />:

<div class="formula">kontrasti = (L₁ + 0,05) / (L₂ + 0,05),   vaihteluväli 1:1 … 21:1</div>

| Kohde | AA-vaatimus | Kriteeri |
|---|---|---|
| Leipäteksti | vähintään 4,5:1 | 1.4.3 |
| Suuri teksti (vähintään 18 pt tai lihavoituna 14 pt) | vähintään 3:1 | 1.4.3 |
| Käyttöliittymäkomponentit ja grafiikka, esimerkiksi kentän reuna tai kaavion viiva | vähintään 3:1 | 1.4.11 |

Matala kontrasti on yleisin automaattisesti havaittu saavutettavuusvirhe: WebAIM Million 2026 -analyysissä sitä oli 83,9 %:lla miljoonan suosituimman sivuston etusivuista <Reference id="webaim-million" />.

WCAG 3 on vielä työluonnos (10.9.2026), eikä sen kontrastialgoritmia ole päätetty <Reference id="wcag3-wd" />. Voimassa oleva vaatimus on siis WCAG 2.2:n kontrastisuhde.

## 2.3 OKLCH-väriavaruus

`oklch()` ilmaisee värin Oklab-väriavaruudessa kolmella koordinaatilla: koettu vaaleus *L* (0–1), kroma *C* eli värin määrä (käytännössä 0–0,4) ja sävykulma *H* <Reference id="mdn-oklch" />. HSL:n vaaleus ei vastaa koettua vaaleutta: keltainen ja sininen samalla HSL-vaaleudella näyttävät eri vaaleilta. OKLCH:n *L* on suunniteltu vastaamaan koettua vaaleutta, joten väriasteikko on helpompi rakentaa muuttamalla vain *L*:ää.

```css
:root {
  --brand-900: oklch(0.30 0.10 260);
  --brand-500: oklch(0.60 0.15 260);
  --brand-100: oklch(0.95 0.03 260);
}
```

Ominaisuus on ollut tuettu kaikissa pääselaimissa toukokuusta 2023 <Reference id="mdn-oklch" />. Tasainen *L* ei kuitenkaan takaa kontrastia, koska WCAG:n kaava käyttää eri luminanssimallia. Tarkista jokainen teksti–tausta-pari kontrastisuhteella.

## 2.4 Liike

Animaatio voi kertoa, mistä uusi elementti tuli tai että toiminto onnistui. Sama liike voi kuitenkin aiheuttaa joillekin pahoinvointia tai viedä huomion tekstiltä. WCAG asettaa kaksi rajaa <Reference id="w3c2023" />:

- **2.2.2 Pause, Stop, Hide (A):** automaattisesti liikkuva sisältö, joka kestää yli viisi sekuntia, pitää voida pysäyttää.
- **2.3.3 Animation from Interactions (AAA):** vuorovaikutuksen käynnistämän liikkeen pitää voida poistaa käytöstä.

Käyttöjärjestelmän asetus "vähennä liikettä" näkyy CSS:ssä mediakyselynä:

```css
@media (prefers-reduced-motion: reduce) {
  .hero-animation { animation: none; }
  * { scroll-behavior: auto; }
}
```

Poista asetuksen ollessa päällä erityisesti suuret siirtymät, parallaksi ja automaattinen vieritys. Pieni värin tai läpinäkyvyyden muutos tilan merkkinä voi jäädä.

## 2.5 Efektit ja niiden riskit

- **Läpikuultava pinta** (`backdrop-filter: blur()`): tekstin kontrasti riippuu siitä, mitä pinnan alla sattuu olemaan, joten se voi alittaa vaatimuksen osassa näkymää. Lisää pinnalle riittävän peittävä taustaväri ja tarkista kontrasti huonoimmassa kohdassa.
- **Kohokuviopinnat** (neumorfismi): painike erottuu taustasta vain varjolla, jolloin komponentin 3:1-kontrastivaatimus (1.4.11) jää helposti täyttämättä.
- **Väri ainoana merkkinä:** WCAG 1.4.1 (A) kieltää välittämästä tietoa pelkällä värillä. Virheellisellä kentällä pitää olla myös teksti tai kuvake.

## Sudenkuopat

- **Kiinteät pikselikoot ja korkeudet.** Teksti ei suurene, tai suurennettu teksti leikkautuu.
- **Kontrasti tarkistetaan vain päävärille.** Tarkista myös harmaat apu­tekstit, paikkamerkit (placeholder), linkit ja tilavärit.
- **Animaatio, jota ei voi poistaa.** Kunnioita `prefers-reduced-motion`-asetusta.
- **Uusi standardi ennen aikojaan.** WCAG 3:n luonnos ei ole vaatimus. Mittaa WCAG 2.2:n mukaan.
